# Atlas Learning Quest

Build a mobile-first educational entertainment app called Atlas (working title).



Combine an entertaining educational video feed with a game-like progression system.



Create 4 working sections:



1. Discover: scrollable educational content cards covering psychology, science, history, technology, creativity and business.

2. World: a visual skill tree where knowledge unlocks new areas.

3. Quests: interactive quizzes, mysteries and challenges with XP rewards.

4. Profile: user interests, ambitions, level and learning progress.



Design:



- Dark, modern, premium gaming aesthetic.

- Visually engaging, similar in polish to TikTok and modern games.

- Mobile-first layout.

- Bottom navigation between the 4 sections.

- Animated progress, XP and level indicators.

- Use realistic sample content.

- Buttons and navigation must work.

- No backend, accounts, payments or API integrations yet.



Build a working frontend prototype, not just a static design.
